01 The system

A software safety layer between every file and the printer.

PrintGuard can run as a cloud service called through an API or directly on printer hardware. Either way, the same classifier screens each file before fabrication and only releases jobs that clear the configured firearm-part policy.

02 The gap

A geometry problem cannot be solved by a list of names.

A
school_project_v8.stl final_final_part.stl untitled_mesh_03.stl

Filenames are fragile

Names can be changed in seconds. Keyword filters confuse intent with a label.

B
6e9a 14f3 03b8 7a21 911c 7d02 bb4a 19e0

Hashes only match exact files

A small file edit produces a new hash, even when the underlying geometry is effectively unchanged.

C

Geometry is the durable signal

PrintGuard extracts mesh statistics, sampled points, voxel occupancy, and multiview projections from the file itself.
