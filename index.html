01 The system

A software safety layer between every file and the printer.

PrintGuard can run as a cloud service called through an API or directly on printer hardware. Either way, the same classifier screens each file before fabrication and only releases jobs that clear the configured firearm-part policy.

Step 03

What the model actually sees.

The classifier never sees your file. It sees a normalised point sample of the surface, reduced to an occupancy grid, three flattened silhouettes and two distance histograms. That abstraction is the whole input.

Input handling Single mesh files Sandboxed parsing with archive, memory and timeout limits

Read this before drawing conclusions

  • A score is a model output, not a legal determination. Thresholds and the actions behind them are policy, set per deployment.
  • v1 mini is trained to separate firearm-related components from close benign mechanical parts. Novel or heavily modified geometry can fall outside what it has seen.
  • The browser samples the mesh surface with a different random stream than the Python reference. Across the held-out set that moves a score by a median of 0.0008 and changed no decisions, but it is not bit-identical.
  • STEP and STP files need CAD-kernel conversion to a mesh format before anything here can read them.
